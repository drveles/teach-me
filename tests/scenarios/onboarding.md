# Start a Subject

## User

I am learning distributed systems for backend interviews. Make it part of relevant future sessions and start teaching me now.

## Required

- Ask for the concrete outcome only if it is missing.
- Persist the mission before promising future continuity.
- Establish trusted sources, a concept plan, and an initial diagnostic.
- Ask one question at a time.

## Reject

- Claiming future continuity without persisted state.
- Starting with an unsourced lecture.
- Treating exposure as learning evidence.
